Variables & Values

Understand bindings, primitive values, reassignment, and the difference between const and let.

12 min
const vs letprimitivesassignment
Tip

A variable is a named binding to a value. Prefer const unless the binding itself must change.

Example 
const price = 42;
let quantity = 2;
const total = price * quantity;

console.log(total);
